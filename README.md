# CampusHub 🎓

> One platform for student life beyond the classroom.

CampusHub is a student-powered community platform built for college students. It helps students find off-campus housing, buy/sell/rent items, recover lost belongings, discover opportunities, and stay updated with campus events.

---

## Features

- 🔐 Student Authentication (Register, Login, JWT, OTP)
- 🏠 Housing (Room Available & Roommate Needed)
- 🛒 Marketplace (Buy, Sell, Rent)
- 📦 Lost & Found
- 💼 Opportunities (Internships, Hackathons, Workshops)
- 📅 Events (Campus Events)
- ❤️ Saved Posts
- 🛡️ Admin Panel

---

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React 18 + Vite + Tailwind CSS |
| Backend | FastAPI + SQLAlchemy + Pydantic |
| Database | PostgreSQL |
| Auth | JWT (Access + Refresh) + Email OTP |
| Images | Cloudinary |
| DevOps | Docker + GitHub Actions + AWS EC2 + Nginx |
